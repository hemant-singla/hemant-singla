#### Featured project: [Walmart demand planning](https://github.com/hemant-singla/walmart-demand-planning)

Which forecasts can a planner trust, and which five items deserve review each week? Three forecasting methods on five years of daily Walmart (M5) sales, a sealed 4-week holdout, a SQL audit of every number, and a 10-page Power BI report.

- Best model **21% more accurate** than the standard baseline on the hidden final four weeks
- 90% forecast ranges caught **89%** of actual sales
- A 5-item weekly review list caught **5×** more forecast error than random picks
